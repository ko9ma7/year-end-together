[기존 GitHub 페이지가 열리는데 시트 저장이 안 되는 경우]

1) START-HERE-KO.md를 먼저 읽으세요.
2) 원본 Google Sheet > 확장 프로그램 > Apps Script > apps-script/Code.gs 붙여넣기.
3) setupSheets 실행, 배포 > 웹 앱 > 나로 실행 / 모든 사용자.
4) 발급된 /exec 주소를 config.js의 appsScriptUrl에 넣기.
5) UPDATE-EXISTING-GITHUB.cmd 실행.
6) GitHub Pages를 다른 브라우저에서 열어 함께 조회되는지 확인.

이 버전은 연결 전 미리보기 저장을 하지 않습니다.
모임 관리 비밀번호는 모임마다 설정되며, 시트에 저장되지 않고 서버 Script Properties에 해시로 보관됩니다.
