Windows Git "Filename too long" 오류 해결

1. PowerShell 실행:
   git config --global core.longpaths true

2. 프로젝트 전체 폴더를 짧은 경로로 옮기기:
   C:\YE\year-end-together
   - .git 숨김 폴더도 포함해서 이동하세요.
   - 이동이 어려우면 ZIP을 C:\YE 폴더에 새로 압축 해제하세요.

3. 새 폴더에서 github-bootstrap.cmd 재실행

진행된 GitHub CLI 로그인은 유지됩니다. 시트 설정을 다시 만들 필요 없습니다.
Google Sheets에 실제 저장하려면 별도로 Google Apps Script를 배포하고 config.js에 /exec 주소를 연결해야 합니다.
